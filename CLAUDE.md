# xo-umbrella2

## Agent skills

### Issue tracker

Issues and specs live as markdown under `.scratch/<feature-slug>/` (spec at
`spec.md`, tickets under `issues/NN-<slug>.md`). See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context — `CONTEXT.md` + `docs/adr/` at the repo root, created lazily by
`/domain-modeling` when terms or decisions get resolved. See `docs/agents/domain.md`.
