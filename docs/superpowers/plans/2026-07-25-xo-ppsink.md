# xo-ppsink Carve-Out Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extract the arena-free pretty-print front-end (`PpSink`/`FlatSink`/`Pretty`/`FunctionStyle`) from `xo-indentlog2` into a new low-level repo `xo-ppsink`, so subsystems below `xo-arena` (e.g. `xo-arena`, `xo-facet`) can pretty-print without depending on the arena-backed engine.

**Architecture:** `xo-ppsink` is a small shared library (namespace `xo::print`, include stem `xo/ppsink/`) depending only on `xo-cmake` (build tooling) + `xo-timeutil` (propagated, anticipating a later `xo::scope` migration). `xo-indentlog2` keeps the arena-backed engine (`PpState`, `PrettySink`, `PpToken*`, `PpConfig`, and the `Pretty` specializations) and gains a dependency on `xo-ppsink`. End-state level order: `xo-timeutil → xo-ppsink → … → xo-arena → xo-indentlog2`.

**Tech Stack:** C++20, CMake + xo-cmake macros, Nix (`pkgs/*.nix` + `xo.nix`/`ci.nix`/`shells.nix`), Catch2 for tests, git-subrepo for the umbrella.

## Global Constraints

- Namespace stays **`xo::print`** — do NOT rename to `xo::ppsink`.
- Cross-repo includes use angle brackets `<xo/…>`; same-repo includes use quotes `"…"`.
- Test `.cpp` files: **no anonymous namespaces** (unity-build friendly); give test-local types unique suffixed names (e.g. `Point_PpsinkTest`) to avoid ODR clashes.
- `xo-ppsink` sits below `xo-testutil`, so its utest uses **plain Catch2** (`#define CATCH_CONFIG_MAIN`), never `xo/testutil`.
- The carve set is exactly: headers `PpSink.hpp`, `FlatSink.hpp`, `Pretty.hpp`, `FunctionStyle.hpp`; sources `PpSink.cpp`, `FlatSink.cpp`. Everything else in `xo-indentlog2/.../print/` stays.
- After any change to `xo-indentlog2` inter-repo deps, the `find_dependency()` set in `xo-indentlog2/cmake/xo_indentlog2Config.cmake.in` and the nix inputs in `pkgs/xo-indentlog2.nix` must stay consistent with the `xo_dependency()` calls.

using xo::print::FlatSink;
using xo::print::PpSink;

TEST_CASE("flatsink-put-and-noop-structure", "[flatsink]") {
    /* FlatSink writes put() text straight through; begin/split/end are no-ops */
    std::stringstream ss;
    FlatSink sink(ss);

    sink.put("hello").begin().put("a").split().put("b").end().put("!");

    /* stream_open returns an inserter that writes straight to the ostream */
    std::stringstream ss;
    FlatSink sink(ss);
    {
        auto ins = sink.stream_open(64);
        ins << 42 << ' ' << "x";
        ins.finish();
    }
    REQUIRE(ss.str() == "42 x");

- [ ] **Step 8: Write the Pretty/pp_write test (arena-free)**

Create `xo-ppsink/utest/Pretty.test.cpp`. Note the unique `_PpsinkTest` type names and no anonymous namespace (unity-build friendly):

```cpp
/* @file Pretty.test.cpp */

#include <xo/ppsink/Pretty.hpp>
#include <xo/ppsink/FlatSink.hpp>
#include <catch2/catch.hpp>
#include <ostream>
#include <sstream>

using xo::print::FlatSink;
using xo::print::PpSink;
using xo::print::Pretty;
using xo::print::pp_write;
using xo::print::has_pretty;

/* a type that opts in to Pretty */
struct Point_PpsinkTest { int x; int y; };

/* a type that does NOT opt in -> pp_write falls back to operator<< */
struct Plain_PpsinkTest { int v; };

inline std::ostream &
operator<<(std::ostream & os, const Plain_PpsinkTest & p) {
    return os << "Plain{" << p.v << "}";
}

namespace xo::print {
    template <>
    struct Pretty<Point_PpsinkTest> {
        static void print(PpSink & sink, const Point_PpsinkTest & p) {
            sink.begin().put("(");
            pp_write(sink, p.x);
            sink.put(",");
            pp_write(sink, p.y);
            sink.put(")").end();
        }
    };
}

TEST_CASE("pp_write-uses-specialization", "[pretty]") {
    static_assert(has_pretty<Point_PpsinkTest>);

    std::stringstream ss;
    FlatSink sink(ss);
    pp_write(sink, Point_PpsinkTest{1, 2});   /* begin/end are no-ops in FlatSink */

    REQUIRE(ss.str() == "(1,2)");
}

TEST_CASE("pp_write-falls-back-to-operator<<", "[pretty]") {
    static_assert(!has_pretty<Plain_PpsinkTest>);

    std::stringstream ss;
    FlatSink sink(ss);
    pp_write(sink, Plain_PpsinkTest{7});      /* stream_open -> operator<< */

    REQUIRE(ss.str() == "Plain{7}");
}
```

## Notes for the executor

- The carve headers are **copied** in Task 1 and the originals **deleted** in Task 2, deliberately: it keeps each task at a green, independently-reviewable state (Task 1 leaves indentlog2 self-contained; no translation unit ever includes both copies, so there is no ODR clash in the intermediate state).
- `PpSink.cpp` implements `PpSinkInserter` (ctor/dtor/`finish`); `FlatSink.cpp` implements the flat `PpSink`. Both are out-of-line, which is why xo-ppsink is a **shared** library rather than header-only.
- If `nix-build` complains it cannot find `-lxo_timeutil` / `xo_timeutilConfig.cmake` while building a consumer, the propagation is wrong — ensure `xo-timeutil` is in `propagatedBuildInputs` of `pkgs/xo-ppsink.nix` (not `nativeBuildInputs`), mirroring the ratio→reflectutil fix.
